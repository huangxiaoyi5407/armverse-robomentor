# 018 — PID 单关节控制教学实验

> Git evidence: included in the task commit `feat: add PID control teaching lab`.

## 目标提示

为大学 A 组版本增加可解释、可复现的单关节 PID 控制实验。学生可以调整 Kp、Ki、Kd 和目标角度，比较欠调、稳定和过调响应，并读取超调量、稳态误差、上升时间和调节时间。

## 数值与安全边界

- 使用固定 0.01 秒步长和 10 秒仿真时长，不加入随机噪声。
- PID 输出与积分项均显式限幅，避免无限积分累积。
- 被控对象通过泛型 `measure/step` 接口注入，为后续负载、摩擦和惯性模型保留稳定边界。
- 页面明确说明“确定性教学仿真，无随机噪声，不直接控制真实机械臂”。
- 曲线使用可访问 SVG 绘制，不增加图表依赖。

## TDD 证据

数值测试首先因 PID 和指标模块缺失失败；实现后发现初始预设无法清晰区分教学响应，使用同一差分方程校准为欠调 `0.1/0/0.3`、稳定 `12/2/5`、过调 `35/8/0.2`，并验证输出与积分限幅。UI 测试先因 PIDLab 缺失失败，组件完成后通过；页面入口同样先红后绿。
