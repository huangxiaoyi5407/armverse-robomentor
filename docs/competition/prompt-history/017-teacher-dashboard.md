# 017 — 教师工作台与第一波教学闭环

> Git evidence: included in the task commit `feat: add classroom training and teacher analytics`.

## 目标提示

在不使用真实学校数据、登录或后端数据库的前提下，为高校自动化类实验教学增加教师工作台。教师能够查看固定合成班级的可重算指标、常见错误和需关注会话，并下钻事件证据与报告摘要。

## 产品与数据约束

- 学生实验台与教师工作台可直接切换，评委无需登录。
- 指标只调用 `calculateClassMetrics` 和 `groupTrainingErrors` 从展示记录重算。
- 错误分布采用语义化 HTML 故障频次条，不引入图表依赖。
- 需关注会话只来自固定状态字段，不使用 AI 推测学习效果。
- 下钻时间线与报告使用稳定的 `SYN-*` 证据编号，并重复披露合成数据边界。

## TDD 与验收证据

教师工作台测试首先因模块缺失得到红灯；实现指标、错误分布和会话下钻后转绿。页面角色切换测试先因“教师工作台”入口缺失失败，接入后通过。对照正式设计补充事件时间线和报告摘要时，再次先添加失败断言后实现。
