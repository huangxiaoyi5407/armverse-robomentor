# 014 — 实训事件溯源与评分

> Git evidence: included in the task commit `feat: trace and score training sessions`.

## 目标提示

为浏览器实训会话建立可审计、不可倒序、不能被旧会话覆盖的事件链，并从事件事实计算完成度、安全性和操作效率评分。

## 核心约束

- 每条事件携带 sessionId、稳定 eventId、顺序号、相对时间、事件码和严重程度。
- 关节快照必须恰好包含六个有限数值；会话之间的事件、重复 ID 和倒序时间被拒绝。
- 已完成会话不可继续写入，重置后旧 sessionId 的异步结果不能污染新会话。
- SafetyReport 的稳定 finding code 映射为教学事件，Agent 文本不参与最终评分。

## 评分规则

总分为 100 分：完成度 30 分、安全性 50 分、效率 20 分。安全阻断扣 20 分，奇异性或 IK 警告每次扣 5 分；第二次起每次尝试扣 4 分效率分。各分项最低为 0，效率奖励不能抵消安全扣分。

## TDD 证据

事件、评分和状态仓库测试首次运行因模块不存在得到红灯；最小实现后聚焦测试通过。安全报告映射随后单独移除实现并增加回归测试，确认得到 `not implemented` 红灯，再恢复实现得到绿灯。最终聚焦测试为 11/11。
