# 016 — 可追溯实训报告

> Git evidence: included in the task commit `feat: generate traceable training reports`.

## 目标提示

综合实训完成后自动生成可打印或导出 PDF 的结果报告。报告必须来源于当前会话的真实事件链，每项指标都标注证据事件编号，并明确声明演示数据为合成数据。

## 实现约束

- 未完成的会话不能生成报告，任务编号不匹配时拒绝生成。
- 实训用时、操作尝试、安全事件与综合得分都绑定源事件编号。
- 安全警告和阻断保留事件代码、说明与证据编号。
- 报告生成时间使用会话内相对时间，不伪造真实日期或学校数据。
- 打印入口只在报告存在时启用，打印样式只保留报告正文。

## TDD 证据

先添加领域与组件测试，测试因报告模块缺失得到红灯；实现确定性报告模型、报告视图和打印操作后转绿。随后在综合实训测试中先断言完成后出现报告并得到红灯，再将报告接入工作台并恢复通过。
