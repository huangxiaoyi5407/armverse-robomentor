# 010 — 受约束的 AI Provider 与 Demo 回退

> Git evidence: `cc27540`.

## 目标提示

为规划、安全讲解和教学讲解定义严格的结构化输出边界。在线 AI 只能返回白名单动作和有限数值，不得返回可执行代码；未配置密钥或在线服务失败时，系统必须切换到明确标注、可重复的 Demo 数据。

## 安全设计

- Zod 严格对象拒绝未知字段、未知动作、错误维度、NaN 与 Infinity。
- 用户提示拒绝代码块、脚本协议及执行表达式，模型输出永远不直接执行。
- 在线 Provider 对 429 仅重试一次，畸形 JSON、超时及服务错误回退 Demo。
- 用户主动取消直接传播 AbortError，不启动回退任务。
- 服务端路由设置 15 秒中止信号，错误响应不记录或返回密钥。
