# 012 — 发布复现与赛事证据

## 目标提示

把已完成的教学实验台变成评委可在十分钟内复现、可用真实浏览器验证、能清楚区分原创代码与第三方事实/依赖的参赛交付物。

## 验收设计

- 手动 FK：改变关节 1 后，角度显示和末端遥测同步更新。
- IK/轨迹：默认可达目标成功求解，轨迹先预览后播放并完成。
- Agent 安全：覆盖工作区的挑战障碍物必须阻断轨迹，关节最终值不变。
- 五秒帧率：在真实 Chrome 里统计 `requestAnimationFrame`，门槛为平均 30 FPS。

## AI 调试链

首次浏览器测试有两类环境/测试问题：Playwright 浏览器下载在 197.5 MiB 的 0% 处长期无进度，因此改用本机 Chrome；手动关节测试使用 `fill()` 操作 `range` 控件时报 `Malformed value`，改为设置原生 value 并派发冒泡的 input/change 事件。修正后 3/3 路径通过，五秒平均 59.0 FPS。

## 发布边界

README、环境示例、第三方说明、提交检查清单和测试证据一同纳入仓库。密钥、本地缓存、浏览器报告和依赖目录均由 `.gitignore` 排除。
