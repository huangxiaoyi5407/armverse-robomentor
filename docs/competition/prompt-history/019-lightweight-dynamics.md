# 019 — 教学级负载、摩擦与惯性模型

> Git evidence: included in the task commit `feat: model teaching load and friction effects`.

## 目标提示

在 PID 单关节实验中加入可调的关节惯量、负载等效惯量、粘性摩擦和库仑摩擦，使学生能够观察负载与摩擦对角度响应、扭矩、速度和加速度的影响，同时保持 PID 核心对被控对象的泛型接口。

## 模型与安全边界

- 使用确定性的教学级单关节差分模型：总惯量为关节惯量与负载等效惯量之和，摩擦扭矩由粘性项和库仑项组成。
- 参数必须有限；关节惯量必须为正，负载与摩擦参数不得为负，时间步长必须为正。
- 页面默认参数为 `1 / 0 / 0.4 / 0.1`，并显示末态估算扭矩、关节速度和关节加速度。
- 页面精确标注“教学简化模型，不用于真实机械臂选型或安全控制”，不宣称工业精度或真实设备控制能力。

## TDD 证据

纯函数测试先覆盖静止、负载惯量、粘性摩擦、非法参数和 10000 步有限性；界面测试随后因缺少四项控件与状态区域按预期失败。实现将 `stepTeachingJointPlant` 注入通用 PID plant 接口，并让模拟结果保留泛型末态用于教学遥测。默认库仑摩擦会让原欠调 `Kp=0.1` 完全静止，因此按实际响应重新校准为 `0.2/0/0.3`；稳定与过调预设保持不变。
