# 015 — 柔性制造综合实训与错误溯源

> Git evidence: included in the task commit `feat: add flexible manufacturing training workspace`.

## 目标提示

在不移除七章原理实验的前提下，增加面向高校自动化与智能制造课程的柔性产线综合实训，并把真实仿真操作和确定性安全结果记录成可筛选的错误溯源时间线。

## 交互设计

- 顶部工作区在“课程实验”和“综合实训”之间切换，原有 UR5 场景、遥测和三 Agent 区域保持原位。
- 综合实训以取料、检测、放料流程为主线，任务步骤采用类似车间工艺流转单的横向结构。
- 合成数据声明使用琥珀色边界条固定显示；安全阻断沿用红色，正常证据沿用青色。
- 错误事件呈现“原因—算法依据—修正建议”，不使用泛化聊天回答。

继续使用项目既有字体、暗色工业网格、青色遥测和琥珀色动作强调，没有引入新字体、图表库或装饰性动画。真实 Chrome 截图复核后保留了一个主视觉焦点：三维机械臂；实训与溯源区域作为安静的工艺记录层，避免与场景争夺注意力。

## 数据连接

IK 求解向实训会话发出尝试、目标、成功/失败和预览事件；三 Agent 工作流把最终 SafetyReport 写入当前 sessionId。旧会话、已完成会话和课程实验模式不会接收综合实训事件。

## TDD 与浏览器证据

组件测试首先因 TrainingWorkspace 缺失得到红灯；实现任务卡、事件过滤和合成数据声明后转绿。随后为 RobotScene、IK 和 WorkflowPanel 增加回调测试，确认最初没有事件回调的红灯，再实现窄接口。首页切换测试同样先因“综合实训”按钮不存在失败，接入后通过。

本地真实 Chrome 完成一次安全挑战：Agent 轨迹被阻断，错误溯源筛选后同时显示 `SAFETY_BLOCKED`、确定性安全门原因和修正建议，页面错误为 0。
