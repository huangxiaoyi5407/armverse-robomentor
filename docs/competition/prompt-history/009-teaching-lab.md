# 009 — 七章教学实验台

## 目标提示

将现有 UR5 三维仿真组织为面向自动化类专业学生的七章交互实验室。页面必须同时呈现课程导航、可操作三维实验台、实验步骤、末端位姿、奇异性指标和齐次变换矩阵；章节切换必须先取消正在执行的轨迹，再恢复章节预设姿态。

## 约束与设计取舍

- 复用 Zustand 仿真状态与纯 TypeScript 运动学内核，不复制计算逻辑。
- 采用深色自动化实验台视觉：青色表示运动学信号，琥珀色表示操作重点与告警。
- 七章覆盖坐标系、DH、正运动学、逆运动学、雅可比、轨迹安全和多 Agent 挑战。
- 全部交互使用原生按钮与语义区域，保留键盘可达性。
