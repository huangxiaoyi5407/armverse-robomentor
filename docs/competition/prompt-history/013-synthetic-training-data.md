# 013 — 合成教学数据与班级指标

> Git evidence: included in the task commit `feat: add transparent synthetic training dataset`.

## 目标提示

为 A 组晋级版建立可复现的高校实验教学示例数据，但不得声称数据来自学校、教师或真实学生，也不得虚构用户试用和教学效果。

## 数据设计

- 固定展示一个“自动化 2301 班（合成示例）”、30 个匿名合成学生和 3 个实验任务。
- 学生、任务和会话 ID 使用稳定规则生成，不使用 `Math.random`、真实姓名、学校名称或外部数据。
- 每个会话只包含完成状态、尝试次数、安全得分和稳定错误码等展示教师分析所需的最小字段。
- 页面后续必须显示“教学演示合成数据，不代表真实学生表现”。

## 指标边界

班级完成率、平均尝试次数、平均安全得分、需要辅导数量和错误频次均由纯 TypeScript 函数从会话记录重算。空数据返回有限的零值；NaN、Infinity、越界得分和非正尝试次数被明确拒绝。

## AI 协作与取舍

接受了“固定种子、可追溯、可重算”的建议，但进一步收紧为完全确定性的规则数据，避免伪随机种子实现被误读为抽样调查。拒绝添加姓名、学号、院校 Logo、真实课程成绩和未经验证的学习提升结论。

测试先于实现创建，首次运行因 `synthetic-data` 和 `analytics` 模块不存在而得到预期红灯；实现后 6/6 聚焦测试通过，全量测试为 18 个文件、140/140 通过。
