# 《臂境智教》6 分钟参赛演示脚本

## 录制规格

- 画面：1920×1080，浏览器缩放 100%，隐藏个人书签、通知和密钥信息。
- 声音：普通话旁白；鼠标移动放慢，关键结果停留 2—3 秒。
- 环境：使用通过阶段 9 验收的生产构建；开场先展示无密钥 `Demo 演示模式`。
- 证据边界：不声称真实学生试用、教学效果提升、工业精度或真实 UR5 连接。

## 0:00—0:25 问题与作品定位

**画面**：首页全景，依次指向“学生实验台”“教师工作台”和四个实验工作区。

**旁白**：

> 自动化专业的机械臂实验，常见问题不是缺少动画，而是原理、操作、安全和实验评价彼此割裂。臂境智教是一套面向高校自动化与机器人工程教学的 UR5 数字孪生实验平台。它把运动学、轨迹规划、确定性安全校验、多智能体讲解、过程记录和控制实验放进同一个无需账号、无需云端密钥的网页。

## 0:25—1:00 数字孪生与机器人算法

**操作**：拖动关节 1；展示机械臂姿态、末端 XYZ、奇异性指标和 4×4 齐次矩阵同步变化。输入默认可达目标，点击“求解逆运动学并预览”，再播放轨迹。

**旁白**：

> 拖动任一关节，三维模型和实时遥测由同一组关节状态驱动。正运动学、数值逆运动学、雅可比矩阵、奇异性分析和轨迹插值均由项目中的纯 TypeScript 模块独立计算。目标可达不代表可以执行；生成的每条轨迹还要经过关节限位、工作空间、位姿一致性、碰撞和奇异风险检查。

## 1:00—1:40 三 Agent 与安全对比

**操作**：先运行普通 Agent 指令，展示规划、安全校验、教学解释时间线和机械臂执行；再勾选“启用安全挑战障碍物”，重复运行，停在阻断结果和未改变的最终姿态。

**旁白**：

> 系统包含规划 Agent、安全督导 Agent 和教学评价 Agent。Agent 负责把自然语言转成白名单动作并解释结果，但没有执行特权。第一次任务通过确定性安全门后自动播放。第二次加入禁入区，轨迹被安全引擎阻断，机械臂保持原姿态。这里的关键创新不是让模型替代安全算法，而是让模型解释可验证的算法事实。

## 1:40—2:30 综合实训、错误溯源与报告

**操作**：进入“综合实训”，开始任务；制造一次安全阻断；在事件时间线展示错误码与“原因—依据—修正”；完成实训并展示报告中的分数、证据 ID 和合成数据声明。

**旁白**：

> 综合实训以柔性制造搬运为主线，记录目标修改、求解、预览、播放、阻断和完成事件。每条记录都有稳定会话 ID、时间和错误码。报告中的完成度、安全得分和关键结论都引用对应事件 ID，不允许出现没有来源的指标。班级、学生和成绩均为固定合成数据，页面明确标注：教学演示合成数据，不代表真实学生表现。

## 2:30—2:55 教师工作台

**操作**：切换“教师工作台”，展示完成率、平均尝试次数、安全得分、错误分布和需关注会话；进入一条会话详情。

**旁白**：

> 教师工作台不依赖后端数据库。所有班级指标都由版本库中的固定合成记录一次重算，可追溯到具体会话和错误事件。它用于演示教学分析流程，不用于声称真实教学效果。

## 2:55—3:30 PID 与教学级动力学

**操作**：进入“PID 控制实验”，依次点击欠调、稳定和过调预设；调整负载等效惯量；展示响应指标、曲线和教学模型状态。

**旁白**：

> PID 实验采用固定步长和确定性计算，学生可以比较欠调、稳定和过调响应，并读取超调量、稳态误差、上升时间和调节时间。进一步调整关节惯量、负载等效惯量、粘性摩擦和库仑摩擦，可以观察估算扭矩、速度和加速度。该模型明确标注为教学简化模型，不用于真实机械臂选型或安全控制。

## 3:30—4:00 工业接口模拟

**操作**：进入“工业接口实验”，完成模拟连接，发送心跳、读取六关节遥测；展示 ROS 2 JSON 导出按钮；触发急停并展示导出按钮禁用。

**旁白**：

> 系统可以导出 ROS 2 JointTrajectory 兼容 JSON，并通过纯状态机演示连接、心跳、遥测、急停和故障。只有与确定性安全报告完全一致的已审批轨迹才能排队。页面明确说明接口模拟，未连接真实机械臂。

## 4:00—5:30 AI 协作与可复现证据

**画面**：切换到 Git 提交历史、`docs/competition/prompt-history`、实施计划、恢复台账和测试证据；显示阶段提交而不是滚动全部源码。

**旁白**：

> 本项目保留了可复现的 AI 协作过程。需求被拆成十个阶段，每个阶段先写失败测试，再实现、全量验证、更新恢复台账并独立提交。仓库保存 Prompt 历史、设计规格、实施计划、关键裁决和细粒度 Git 记录。AI 不是黑盒代写者，而是受测试、文档和版本历史约束的协作工具。

## 5:30—6:00 验证结果与收束

**画面**：展示测试证据表；最后回到首页。

**旁白**：

> 最终干净复现安装 497 个包用时 22 秒；31 个测试文件共 184 项测试、8 条真实 Chrome 验收、lint 和生产构建全部通过，生产依赖审计为零漏洞，代表性五秒帧率为 58.3 FPS。臂境智教希望让机械臂实验既能动、能算、能解释，也能在危险动作发生前可靠地停下来。

- 报告画面同时出现证据 ID 与合成数据声明。
