# 臂境智教｜评审亮点一页纸

## 一句话定位

面向高校自动化与机器人工程实验教学，把 UR5 数字孪生、机器人算法、确定性安全、多 Agent 讲解、实训证据和控制实验放进一个无需账号与云端密钥的可复现网页。

## 评委建议体验路线（5—8 分钟）

1. 拖动关节，观察三维姿态、末端位姿、奇异性和矩阵同步变化。
2. 求解可达目标并播放安全轨迹；开启障碍物挑战，确认危险轨迹被阻断且姿态不变。
3. 完成综合实训，查看错误溯源和带事件证据 ID 的报告。
4. 切换教师工作台，查看由固定合成记录重算的班级指标。
5. 比较 PID 欠调、稳定、过调响应并调整负载、摩擦与惯性。
6. 在工业接口实验中连接、读取遥测、触发急停，确认导出被禁用。

## 三个核心亮点

### 1. Agent 会解释，但不能越过安全门

规划 Agent 生成白名单动作，安全督导与教学评价 Agent 解释结果；最终执行权始终属于确定性关节限位、工作空间、位姿一致性、碰撞和奇异风险检查。

### 2. 教学结果可追溯，不是装饰性看板

实训采用只追加事件记录。报告指标引用来源事件 ID；教师工作台指标由固定合成会话重算。所有页面明确披露“教学演示合成数据，不代表真实学生表现”。

### 3. A 组技术深度与产品闭环并存

项目不仅展示 3D 场景，还独立实现 FK、IK、雅可比、轨迹、安全、PID、负载/摩擦/惯性教学模型、ROS 2 兼容 JSON 和设备网关状态机。

## 明确边界

- 没有使用真实学校、教师、学生或企业生产数据。
- 没有声称学生试用、问卷研究或教学效果提升。
- 动力学是教学简化模型，不用于真实机械臂选型或安全控制。
- ROS 2 与设备网关均为接口模拟，未连接真实 UR5。
- UR5 外形为程序化教学几何，不包含厂商 CAD、Logo 或受限素材。

## 作品价值

让学生不仅看到机械臂“动起来”，还能够理解为什么这样动、何时不能动、错误如何修正，以及每个实验结论来自哪一条可验证证据。
