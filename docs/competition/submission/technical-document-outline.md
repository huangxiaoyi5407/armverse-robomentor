# 《臂境智教》技术文档大纲（30 页以内）

## 编写原则

- 建议正文 26—28 页，预留 2—4 页给封面、目录和平台要求。
- 每个结论对应代码、测试、截图或 Git/Prompt 证据；没有证据的功能不写入完成项。
- 截图必须来自通过阶段 9 验收的生产构建，统一标注录制日期和页面位置。
- 不使用真实学校、学生、教师或企业生产数据，不宣称教学效果提升或工业控制精度。

## 公式与实现对应

- DH 齐次变换与 FK：对应 `src/robotics/kinematics`。
- 阻尼最小二乘 IK：给出误差、阻尼和收敛条件，不夸大解析精度。
- 雅可比与奇异性指标：解释最小奇异值和可操作度。
- 三次/五次轨迹插值：给出端点速度条件。
- PID：给出比例、积分、微分、输出限幅和积分限幅。
- 教学 plant：`acceleration = (inputTorque - frictionTorque) / (inertia + payloadInertia)`。
- 班级指标与评分：给出可重算定义及异常输入处理。

## 附录取舍

- 不粘贴大段源码；每个模块最多放 10—20 行关键片段并标注仓库路径。
- 不把完整测试日志塞入正文；正文放汇总表，原始证据保留在仓库。
- 第三方许可证只做摘要，完整来源链接指向 `third-party-notices.md`。
- 若平台严格计算封面和目录页，优先压缩数字孪生界面与工程实现章节，不删除安全边界和验证章节。
