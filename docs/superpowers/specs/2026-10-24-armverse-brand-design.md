# 臂境智教品牌统一设计

## 意图

将当前参赛作品的对外名称统一为“臂境智教——基于数字孪生与多智能体协同的UR5机械臂教学实验平台”，使页面、仓库简介和参赛入口材料使用同一品牌。

## 范围

- 页面主标题和 Next.js 元数据使用“臂境智教”。
- README 使用正式全称，并写入最终私有仓库地址。
- npm 包标识与仓库名统一为 `armverse-robomentor`。
- 提交检查清单标记仓库地址已完成。

## 非目标与证据边界

- 不修改功能、视觉布局、算法或测试逻辑。
- 不回写历史 Prompt、原始设计文档和实施计划中的 `RoboMentor UR5`，以保留开发过程证据。
- 不操作用户的其他 GitHub 仓库。

## 方案

采用已确认的“中文品牌短名＋技术与场景副标题”方案。仓库使用便于链接与部署的英文 slug `armverse-robomentor`；用户可见界面优先显示中文品牌。
