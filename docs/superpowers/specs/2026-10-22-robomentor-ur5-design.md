# RoboMentor UR5 产品与技术设计

## 1. 项目概述

RoboMentor UR5 是面向自动化类专业学生的六自由度机械臂运动学交互教学平台。它通过 UR5 3D 仿真、实时数学参数、轨迹回放和多 Agent 教学工作流，帮助学生理解 DH 参数、坐标变换、正逆运动学、雅可比矩阵、奇异点和轨迹规划。

本项目参加 2026 第九届传智杯 AI 创新应用挑战赛，对应“数字孪生与轻量具身智能仿真”方向。

## 2. 用户、问题与成功标准

### 2.1 目标用户

- 正在学习机械臂运动学、机器人技术或智能控制的自动化类本科或高职学生。
- 需要通过直观实验验证公式和算法的学生。
- 需要可重复教学演示的机器人技术、运动控制或智能制造课程教师。

### 2.2 核心问题

传统教材中的矩阵、坐标系和运动学公式较抽象，学生很难建立关节参数、末端位姿、奇异性和实际机械臂运动之间的直观联系。现有工业仿真软件安装复杂、学习成本高，且缺少对求解过程和失败原因的个性化解释。

### 2.3 成功标准

- 学生可以手动调节六个关节并实时观察末端位姿和坐标变换。
- 学生可以指定目标位姿，观察逆运动学的收敛过程和误差。
- 系统能对奇异点、越界和碰撞风险做出可解释的确定性判断。
- 学生可以用自然语言提交任务，观察规划、审查、执行和讲解全过程。
- 无云端 AI 密钥时仍能体验主要教学功能和内置 Agent 案例。
- 在新环境中可根据 README 于 10 分钟内启动。

## 3. 范围与分阶段路线

### 3.1 省赛必做版

- UR5 六自由度 3D 模型与六关节手动控制。
- DH 参数表、各级坐标系和变换矩阵。
- 正向运动学与阻尼最小二乘数值逆运动学。
- 几何雅可比矩阵、最小奇异值、可操作度和奇异风险。
- 关节空间三次/五次插值和笛卡尔空间直线轨迹。
- 简化障碍物、工作空间、关节限位和碰撞检查。
- 规划、安全审查和教学解释三 Agent 顺序工作流。
- 真实云端 AI 模式与无密钥演示模式。
- 七个教学章节、内置实验、轨迹回放和执行日志。

### 3.2 省赛加分版

- 更真实的 UR5 外观模型、末端抓取器和物体搬运。
- 更精确的碰撞检测和用户自定义障碍物。
- 轨迹速度、加速度和平滑性曲线。
- 学习成绩、实验记录和学习报告。
- 多种逆运动学方法对比。

### 3.3 国赛增强版

- 刚体动力学、控制器、电机、负载、摩擦和惯性建模。
- ROS 2 / MoveIt 接口与真实机械臂 WebSocket 连接。
- 摄像头视觉识别、多机械臂协同和高级自主规划。

## 4. 用户流程

1. 学生选择教学章节或内置实验。
2. 学生在 3D 场景中识别 UR5 关节和坐标系。
3. 学生拖动关节滑块，实时观察机械臂姿态、末端位姿和变换矩阵。
4. 学生输入或拖动目标位姿，运行逆运动学。
5. 系统显示误差收敛、求解结果、雅可比数据和奇异风险。
6. 学生选择轨迹类型，比较不同轨迹的运动表现。
7. 在安全挑战中，学生输入自然语言任务。
8. 系统依次展示规划、确定性验证、安全审查、仿真执行和教解。
9. 学生回放轨迹，查看成功或失败原因。

## 5. 页面和教学设计

### 5.1 主界面

产品采用单一仿真实验台：

- 顶部：章节、实验、在线 AI / 演示模式状态。
- 左侧：当前知识点、公式、实验步骤和思考题。
- 中央：UR5 3D 机械臂、坐标系、目标点、障碍物和轨迹。
- 右侧：六轴角度、末端位姿、矩阵、雅可比与奇异状态。
- 底部：用户指令及多 Agent 工作流时间轴。

视觉方向为深色工业实验室，3D 机械臂为视觉中心。数学矩阵默认折叠；危险、奇异和碰撞使用一致的红色警示。桌面端优先，移动端仅保证查看。

### 5.2 教学章节

1. 认识 UR5：六关节、坐标系和关节限位。
2. DH 参数与坐标变换：DH 表、坐标系与变换矩阵。
3. 正向运动学：由关节角计算末端位姿并分步显示矩阵连乘。
4. 逆向运动学：由目标位姿求关节角，显示收敛过程和初值影响。
5. 雅可比与奇异点：矩阵、可操作度、奇异风险和难移动方向。
6. 轨迹规划：比较关节空间和笛卡尔空间轨迹。
7. 安全任务挑战：障碍环境下的自然语言任务、Agent 审查与轨迹回放。

## 6. 技术架构

### 6.1 技术栈

- Next.js + TypeScript。
- React Three Fiber / Three.js。
- Zustand。
- Math.js 及自实现的机器人算法模块。
- Next.js API Route 作为云端大模型代理。
- Zod 定义 Agent 协议和运行时校验。
- Vitest 用于算法和服务测试。

### 6.2 分层

1. 教学与界面层：页面、3D 场景、控制面板和学习流程。
2. 仿真状态层：关节角、目标位姿、障碍物、轨迹和播放状态。
3. 确定性计算层：UR5 模型、运动学、雅可比、轨迹和安全算法。
4. Agent 编排层：规划、审查、执行和解释的状态机。
5. AI 适配层：在线模型与内置演示提供者的统一接口。

### 6.3 模块边界

```text
src/
├─ app/                 Next.js 页面与 API
├─ features/
│  ├─ simulator/        3D 场景、机械臂和动画
│  ├─ lessons/          教学章节与实验
│  ├─ agent-workflow/   多 Agent 工作流
│  └─ control-panel/    参数输入与状态展示
├─ robotics/
│  ├─ ur5-model/        UR5 参数和关节限制
│  ├─ kinematics/       正向/逆向运动学
│  ├─ jacobian/         雅可比与奇异点
│  ├─ trajectory/       轨迹规划
│  └─ safety/           越界、碰撞与轨迹检查
├─ ai/
│  ├─ planner/          规划 Agent
│  ├─ reviewer/         安全审查 Agent
│  ├─ tutor/            教学解释 Agent
│  └─ providers/        在线 API 与演示适配器
└─ shared/              类型、数学工具和通用组件
```

运动学、雅可比、轨迹和安全算法必须是不依赖 React 和 3D 场景的纯计算模块。

### 6.4 单位规范

- 内部长度：米。
- 内部角度：弧度。
- 内部时间：秒。
- 界面可将长度和角度转换为毫米和度显示。

## 7. 机器人算法设计

- 使用 UR5 参考 DH 参数建立连杆模型，参数来源必须记入第三方说明。
- 正向运动学使用齐次变换矩阵连乘。
- 逆向运动学首版使用阻尼最小二乘数值法，返回是否收敛、迭代数、位置/姿态误差和失败原因。
- 雅可比使用几何法，奇异检测参考最小奇异值和可操作度。
- 关节空间实现三次与五次插值；笛卡尔直线轨迹通过位姿插值和逐点逆解实现。
- 首版安全检测包括关节限位、工作空间、数值有效性、奇异风险及连杆简化包围体与障碍物包围盒碰撞。

## 8. 多 Agent 设计

### 8.1 职责

- 规划 Agent：将自然语言意图转换为受限的结构化任务。
- 安全审查 Agent：阅读确定性程序产生的检测报告，组织可理解的审查结论。
- 教学解释 Agent：根据真实输入、轨迹和检测结果解释相关概念与失败原因。

### 8.2 工作流

```text
自然语言指令
→ 规划 Agent 生成结构化计划
→ Zod 协议校验
→ 确定性程序计算轨迹和安全报告
→ 安全 Agent 生成审查说明
→ 安全时执行动画，危险时拒绝
→ 教学 Agent 根据真实结果解释
```

### 8.3 安全边界

- Agent 不得生成或执行任意 JavaScript。
- Agent 只能使用预定义动作白名单。
- 工作空间、逆解、限位、奇异点、碰撞和轨迹安全由确定性程序裁决。
- 程序判定危险时必须拒绝，Agent 不能覆盖。
- 教学 Agent 只能使用系统提供的计算数据，不得伪造位姿、误差或安全结论。

## 9. 错误处理与回退

- 无 API 密钥：启用内置演示提供者，界面明确标识。
- AI 超时或限流：告知用户原因并切换演示模式。
- Agent 输出无效：仅重试一次；仍无效时使用规则模板。
- 逆运动学不收敛：保持原机械臂状态，显示误差、迭代次数和建议。
- 目标越界：不执行，在 3D 场景中标红目标。
- 轨迹危险：暂停执行，保留检测点和原因供学习。
- 动画失败：不提交最终仿真状态，防止显示与算法状态不一致。

## 10. 测试和验收

### 10.1 单元测试

- UR5 零位和典型位姿的正向运动学。
- DH 矩阵与坐标变换。
- 逆解结果重新代入正解后的位姿误差。
- 雅可比矩阵与有限差分对比。
- 关节限位、奇异性、轨迹起终点、连续性和碰撞规则。
- Agent JSON Schema 与白名单动作。

### 10.2 集成与端到端测试

- 自然语言任务能转为合法计划。
- 危险计划必须被阻止，安全计划能执行动画。
- AI 错误时能进入演示模式。
- 教学解释仅引用实际计算结果。
- 覆盖手动正运动学、目标位姿逆解、多 Agent 安全任务三条完整用户路径。

### 10.3 验收指标

- 可达且非奇异目标的逆解位置误差不超过 1 毫米。
- 姿态误差不超过 0.5 度。
- 所有轨迹不得突破 UR5 关节限制。
- 碰撞或危险轨迹不得进入执行状态。
- AI 失败后在 15 秒内进入演示模式。
- 典型桌面设备上 3D 交互目标不低于 30 FPS。
- 按 README 在新环境中 10 分钟内启动。
- 无 AI 密钥时七个教学章节和预置 Agent 案例仍可使用。

若数值实现证明指标需要调整，必须在决策记录中说明测试证据和调整原因。

### 11.1 文档结构

```text

├─ prompt-history/
```

### 11.2 Git 策略

- 先记录设计，再实现。
- 每个提交只完成一个清晰目标。
- 核心算法遵循测试先行的红—绿—重构过程。
- 不为制造细粒度记录而伪造无意义提交。
- 不改写已作为参赛证据的历史。

### 11.3 原创性与第三方合规

- 运动学、轨迹、安全规则和 Agent 编排自主实现。
- 不复制现成 UR5 仿真项目。
- 记录所有依赖的名称、版本、用途和许可证。
- 使用模型、图标、字体或教学资料时记录来源。
- README 明确区分自主实现与第三方基础依赖。

## 13. 明确排除项

以下内容不进入省赛必做版：真实机械臂连接、完整刚体动力学、电机与控制器、工业级网格碰撞、多机械臂协同、自主模型训练。架构允许后续增强，但不允许这些项目阻碍省赛核心版完成。
